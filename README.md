# 🧮 Program Kalkulator Sederhana

Proyek ini dibuat untuk latihan dasar pada **Modul 5 - Kegiatan 1**
Tujuannya untuk membuat program kalkulator sederhana menggunakan bahasa Java.

---

## 📘 Deskripsi
Program ini meminta pengguna untuk memasukkan dua angka dan memilih operasi matematika:
penjumlahan, pengurangan, perkalian, atau pembagian.
Program kemudian menampilkan hasil dari operasi tersebut.

---

## ⚙️ Cara Menjalankan
1. Buka file `Main.java` di IntelliJ IDEA.
2. Jalankan program dengan klik tombol ▶️ (Run).
3. Masukkan dua angka dan pilih operasi (+, -, *, /).
4. Hasil perhitungan akan ditampilkan di konsol.
